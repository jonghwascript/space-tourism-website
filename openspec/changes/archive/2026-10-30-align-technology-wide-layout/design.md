# Design

## Context

- **현재 데스크톱 규칙** (`src/scss/pages/_technology.scss`)
  - `.c-technology`: `inline-size: min(79.6875rem, 100% - 2.5rem); margin-inline-start: auto; padding: 3rem 0`. 1275px 상한, 오른쪽 정렬입니다.
  - 그리드 열: `auto max(30.6875rem, 50% - 10rem) minmax(0, 1fr)`, `column-gap: 2rem`. 탭은 `margin-inline-end: 2rem`입니다.
  - 데스크톱 이미지: `img { inline-size: 100%; block-size: 37.5rem; object-fit: cover }`. `picture`는 `justify-self: stretch`라 이미지 열 폭 전체를 채웁니다.
- **다른 페이지:** `inline-size: min(69.375rem, 100% - 5rem); margin-inline: auto`. 1110px 가운데, 좌우 최소 40px입니다.
- **텍스트 열 공식의 실제 동작:** `max(491px, 50% − 160px)`는 영역이 1302px 이하일 때 항상 491px입니다. 지금 영역은 최대 1275px라, 실제로는 모든 데스크톱 폭에서 491px 고정이었습니다.
- **검증 방식:** 캡처는 남기지 않습니다(AGENTS.md). Playwright Chromium과 스크래치 미리보기(`dist` 미사용)로 요소 상자를 측정합니다.

## Goals / Non-Goals

**Goals:**
- 1024px과 1440px(Figma)은 지금과 같은 값을 유지합니다.
- 그 사이 폭에서도 시작선을 다른 페이지와 맞춥니다. 예: 1280px에서 40 → 85, 이미지 568 → 528px(구현 중 확인, 사용자 결정).
- 1440px보다 넓은 화면에서 왼쪽 시작선을 다른 페이지와 맞추고, 이미지를 608×600으로 화면 오른쪽 끝에 붙입니다.

**Non-Goals:**
- 모바일·태블릿, 이미지 자산, 숫자 탭 변경
- 헤더 로고 위치(64px 고정)와 본문 시작선 맞추기. 다른 페이지도 같은 구조입니다.

## Decisions

### 1. 영역: 왼쪽 여백만 계산하고 오른쪽은 화면 끝까지
`.c-technology` 데스크톱 규칙을 바꿉니다.
- `inline-size`를 지우고(자동 폭), `margin-inline-start: max(2.5rem, (100% - 69.375rem) / 2)`로 둡니다.
- 그리드 항목(body 그리드의 `1fr` 열)이라, 자동 폭이 남은 공간(화면 오른쪽 끝까지)을 채웁니다.
- `%`는 body 내용 폭(= viewport) 기준이라, 다른 페이지의 `margin-inline: auto` 결과와 같은 시작선이 됩니다.
- 검산: 1440px은 max(40, 165) = 165, 폭 1275(지금과 같음). 1024px은 max(40, −43) = 40, 폭 984(지금과 같음). 1920px은 405, 폭 1515.
- 처음 검산에서 두 끝점만 보고 "1024~1440px 모두 같다"고 적었지만, 실제로는 다릅니다. 이전 왼쪽 여백은 `max(40px, 화면 − 1275px)`였고 새 식은 `max(40px, (화면 − 1110px) / 2)`라, 그 사이 폭에서는 새 시작선이 오른쪽에 옵니다(1280px에서 40 → 85). 다른 페이지와 같은 선이라 그대로 두기로 했습니다.

### 2. 열: 텍스트 491px 고정, 이미지 열은 남은 폭
- 열을 `auto 30.6875rem minmax(0, 1fr)`로 바꿉니다.
- 기존 `max()` 식은 지금 범위에서 늘 491px이었으므로, 텍스트 폭은 모든 데스크톱 폭에서 491px 그대로입니다. 넓은 화면에서 텍스트 열이 늘어나지 않게 고정값으로 씁니다.
- 대안(기존 식 유지): 1920px에서 텍스트 열이 597px로 늘어나 Figma 텍스트 폭과 달라지므로 제외합니다.

### 3. 이미지: 608px 상한, 열 오른쪽 끝 정렬
- 데스크톱 `picture`를 `justify-self: end; inline-size: min(38rem, 100%)`로 둡니다(608px). `img`는 `inline-size: 100%`를 유지합니다.
- 이미지 열이 608px보다 좁은 1440px 미만에서는 열 폭 전체입니다(1024px 317px, 1280px 528px, 1440px 608px). 넓은 화면에서는 608px로 멈추고 오른쪽 끝에 붙습니다.
- 대안(이미지가 남은 폭 채움): portrait 원본(515×527)이 크게 확대·잘려 사용자가 고르지 않았습니다.

## Risks / Trade-offs

- **[넓은 화면에서 텍스트–이미지 간격이 커짐]** 1920px에서 약 272px입니다. 사용자 결정이며 Figma 정의가 없는 구간입니다.
- **[데스크톱 패널 포커스 테두리]** 패널 상자가 여전히 화면 오른쪽 끝까지라 안쪽 outline(`-2px`) 규칙이 그대로 필요합니다. 측정으로 확인합니다.
- **[텍스트 200%]** em 분기점 때문에 1440px도 모바일 배치가 되어 영향이 없습니다. 측정으로 확인합니다.

## Migration Plan

SCSS 데스크톱 규칙 몇 줄만 바뀝니다. 되돌리면 이전처럼 1275px 오른쪽 정렬이 됩니다.
