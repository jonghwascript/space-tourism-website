# Spec Delta

## MODIFIED Requirements

### Requirement: 데스크톱 Technology 배치
1024px 이상에서 본문 영역은 다른 페이지의 1110px 가운데 영역과 같은 왼쪽 시작선(`max(40px, (화면 폭 − 1110px) / 2)`)에서 시작해 화면 오른쪽 끝까지 SHALL 이어진다(위아래 패딩 48px). 영역 안에는 제목을 위에 두고, 그 아래 한 줄에 다음을 놓는다.
- 숫자 탭: 세로 묶음
- 텍스트 묶음: 왼쪽 정렬, 폭 491px
- 이미지: 폭 608px(열이 더 좁으면 열 폭)·높이 600px, 이미지 열의 오른쪽 끝(화면 오른쪽 끝)에 붙는다

간격은 숫자 탭–텍스트 64px, 텍스트–이미지 32px 이상이며, 세 요소는 서로 세로 가운데를 맞춘다.

#### Scenario: 1440px 배치
- **WHEN** viewport 1440×1024에서 본문을 측정한다
- **THEN** 다음 값이 모두 맞는다(±2px)
  - 제목과 숫자 탭의 왼쪽 끝이 165px
  - 텍스트 묶음 왼쪽 끝이 309px(165 + 80 + 64), 폭 491px
  - 이미지가 x 832~1440px(폭 608), 높이 600px
  - 숫자 탭 묶음·텍스트 묶음·이미지의 세로 중심이 서로 2px 이내

#### Scenario: 분기점 직후
- **WHEN** viewport 1024px에서 같은 측정을 한다
- **THEN** 가로 배치가 적용되고 영역 왼쪽 여백이 40px이며, 텍스트 묶음 폭이 491px이고 이미지가 오른쪽 끝 1024px에 닿으며, 요소가 겹치지 않고 가로 넘침이 없다

#### Scenario: 넓은 화면
- **WHEN** viewport 1920×1080과 2560×1440에서 본문을 측정한다
- **THEN** 제목과 숫자 탭의 왼쪽 끝이 같은 폭의 `destination-moon.html` 제목 왼쪽 끝(1920px에서 405, 2560px에서 725)과 같고, 텍스트 묶음 폭이 491px이며, 이미지가 608×600px이고 오른쪽 끝이 화면 오른쪽 끝과 같으며, 가로 넘침이 없다
