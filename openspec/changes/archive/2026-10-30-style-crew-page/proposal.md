# Proposal

## Why

Crew 페이지 4개(`crew-{commander,specialist,pilot,engineer}.html`)는 마크업만 있습니다. 페이지 제목만 공통 컴포넌트로 스타일이 적용되어 있고, 본문(`c-crew`)과 점 탭(`c-tabs--dots`)에는 스타일이 없습니다. 그래서 승무원 원본 사진이 크게 쌓이고, 점 탭은 숨김 텍스트뿐이라 화면에서 보이지 않습니다. 헤더·홈·Destination과 같은 분기점(768px, 1024px)과 Figma 값(모바일 91:1765, 태블릿 49:1527, 데스크톱 9:2118, hover 99:1808)으로 맞춥니다.

## What Changes

- Crew 페이지에 화면 크기별 배경 이미지(`background-crew-{mobile,tablet,desktop}.jpg`)를 채우고, 본문이 헤더 아래 남은 화면 높이를 최소한으로 채우게 합니다.
- 화면 크기별 본문 배치를 적용합니다.
  - 모바일(768px 미만): 패딩 24px. 세로 가운데 정렬로 제목 → 역할·이름·소개 → 점 탭 → 사진(높이 340px)을 놓습니다.
  - 태블릿(768px 이상 1024px 미만): 패딩 40px. 같은 순서이고, 텍스트 최대 512px, 사진 높이 560px입니다.
  - 데스크톱(1024px 이상): 최대 폭 1110px 2열입니다. 왼쪽 열에는 텍스트(세로 가운데)와 열 아래쪽 점 탭, 오른쪽 열에는 사진(높이 676px)을 놓습니다.
- 마크업은 점 탭이 패널보다 앞에 있지만, 화면에서는 Figma처럼 텍스트 다음에 점 탭이 보이게 배치합니다. DOM 순서는 바꾸지 않습니다(Destination과 같은 방식).
- 사진 아래쪽 약 23%를 투명하게 흐리는 마스크를 적용하고, 원본 비율을 유지한 채 아래쪽 기준으로 표시합니다.
- 역할·이름·소개 타이포그래피를 Figma text-preset 값으로 적용합니다.
- 점 탭 변형(`c-tabs--dots`)을 추가합니다.
  - 점 크기: 모바일·태블릿 10px, 데스크톱 15px
  - 색: 비선택 white 17.4%, 선택 white, hover white 50%
  - 그 밖에 키보드 포커스, 24px 이상의 클릭 영역, 움직임 줄이기, 강제 색상 대응을 포함합니다.
- 320px, 가로 모드, 텍스트 200%에서 가로 넘침과 겹침이 없게 합니다.

범위 밖:
- 승무원 전환 동작(점 탭 클릭 시 패널 전환)과 Splide 같은 슬라이드 라이브러리. 사용자 결정으로 이번에는 스타일만 다룹니다. Figma에 스와이프·전환 애니메이션 정의가 없습니다. 전환은 Destination·Technology와 함께 쓸 탭 스크립트 change에서 다룹니다. 그때까지 비선택 점은 hover 표시만 있고 눌러도 바뀌지 않으며, 이를 보고서에 알려진 제한으로 기록합니다.
- 헤더·홈·Destination 변경, 마크업 텍스트·구조 변경(스타일 연결용 클래스 추가만 허용)
- 이미지 `width`·`height` 속성(모두 496×676)과 실제 원본 비율 차이 수정(보고서에 기록)

## Capabilities

### New Capabilities

없음

### Modified Capabilities

- `crew-page`: 기존 마크업 요구사항은 유지합니다. 다음 요구사항을 추가합니다.
  - 배경 이미지, 본문 높이
  - 화면 크기별 배치, 타이포그래피, 사진 표시·마스크
  - 점 탭 표시 상태(선택·hover·포커스·클릭 영역·움직임 줄이기·강제 색상)
  - 넘침 방지

`content-tabs`의 구조·ARIA·초기 선택 요구사항은 바뀌지 않습니다.

## Impact

- `src/scss/pages/_crew.scss`(신규): 페이지 배경, 본문 배치, 패널 스타일
- `src/scss/components/_tabs.scss`: 점 탭 변형 `.c-tabs--dots` 추가. 기존 공통 바탕과 밑줄형은 바꾸지 않습니다.
- `src/scss/style.scss`: `pages/crew` `@use` 추가
- `src/partials/crew-tabs.html`: 탭 목록에 배치용 클래스 추가만 합니다. 텍스트·ARIA·순서는 바꾸지 않습니다.
- 홈·Destination·Technology·헤더: 변경 없음(computed style·측정값으로 회귀 확인)
- 의존성 추가 없음
